Cara Kerja Update Berita (Mode JSON)

  1. Tambahkan berita atau foto galeri baru melalui menu di samping.
  2. Klik tombol hijau Download data.json di bagian atas.
  3. Buka repositori GitHub / cPanel hosting kamu, lalu unggah file data.json yang baru diunduh untuk menggantikan file lama.
  4. Selesai! Semua pengunjung dari HP maupun laptop lain akan langsung melihat berita terbaru.
